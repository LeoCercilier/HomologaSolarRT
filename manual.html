🚀 Para que serve?

O HomologaSolar RT é uma ferramenta para organizar projetos fotovoltaicos e auxiliar o Responsável Técnico na conferência, documentação e acompanhamento do processo de homologação.

O sistema reúne:

  • 👥 Clientes
  • 👷 Responsáveis Técnicos
  • 📁 Projetos
  • ☀️ Sistemas fotovoltaicos
  • 📋 Templates
  • 📄 Documentos
  • 📊 Cálculos e verificações técnicas
  • 📑 Relatórios

🧭 Como começar

1️⃣ Acesse sua conta

Faça login para acessar o Dashboard.

2️⃣ Cadastre o cliente

Informe nome, CPF/CNPJ, telefone, e-mail e endereço.

3️⃣ Crie o projeto

Escolha o cliente e informe o nome do projeto.

4️⃣ Preencha o sistema

Use um template ou informe os dados manualmente.

5️⃣ Confira a análise

Verifique os cálculos e os alertas apresentados.

6️⃣ Organize os documentos

Adicione os arquivos necessários ao projeto.

7️⃣ Gere o relatório

Revise os dados e gere o relatório técnico.

📋 Templates

Os templates permitem iniciar um projeto com informações previamente configuradas.

Isso reduz o trabalho de preenchimento e ajuda a manter configurações padronizadas.

⚠️ Importante: o template é um ponto de partida. Sempre confira os dados dos equipamentos e adapte-os ao projeto real.

🔎 Análise do dimensionamento

O HomologaSolar RT realiza verificações automáticas com base nos dados informados.

  • Quantidade de módulos × strings
  • Strings × capacidade dos MPPTs
  • Voc × tensão máxima do inversor
  • Vmp × faixa de MPPT
  • Corrente × limite do MPPT
✅ Dimensionamento consistente

Significa que os dados passaram pelas verificações automáticas disponíveis no sistema.

📋 Resultado técnico

🟢 Dimensionamento tecnicamente consistente

Nenhuma incompatibilidade foi encontrada nas verificações automáticas realizadas.

🟡 Atenção

O sistema encontrou um ponto que merece revisão. Confira os dados antes de continuar.

🔴 Inconsistência

Existe uma incompatibilidade nos dados informados. Corrija a configuração e faça uma nova conferência.

📄 Documentação para homologação

Ganhe tempo no processo de homologação. ⚡

O HomologaSolar RT já permite gerar alguns documentos automaticamente em poucos segundos, utilizando as informações preenchidas no projeto.

📑 Documentos disponíveis

  • 📄 Gerar Relatório Técnico
  • 📄 Gerar Memorial Descritivo
  • ✍️ Procuração de Homologação
  • 📜 Declaração de Responsabilidade
  • 📋 Ficha de Acesso
  • 🔍 Checklist de Vistoria
  • 📐 Gerar Diagrama Unifilar
⚡ Mais rapidez, menos trabalho

Os documentos são gerados a partir dos dados cadastrados no projeto, reduzindo o preenchimento manual e ajudando a evitar erros de digitação.

O objetivo é transformar as informações já cadastradas em documentos úteis em poucos segundos.

👷 Conferência do Responsável Técnico

Os documentos gerados são ferramentas de apoio e devem ser conferidos pelo Responsável Técnico (RT) antes de sua utilização ou envio à distribuidora.

A geração automática não substitui a análise, aprovação ou responsabilidade profissional do RT.

🔄 Sistema em evolução

O HomologaSolar RT está em constante aprimoramento.

Sugestões, correções e melhorias indicadas pelos usuários são importantes para a evolução do sistema e poderão ser incorporadas às próximas versões.

💡 Quanto mais o sistema é utilizado, mais podemos aprimorá-lo para tornar o processo de homologação rápido, organizado e eficiente.

🔄 Etapas da homologação

📝 Rascunho
Projeto em preenchimento.
📂 Documentação
Documentos sendo reunidos e conferidos.
📤 Enviado
Documentação enviada.
🔎 Em análise
Processo em avaliação.
✅ Aprovado
Homologação aprovada.
❌ Reprovado
Necessita de correção ou nova análise.

📑 Relatório técnico

📄 Gerar relatório PDF

📋 Duplicar projeto

Utilize a opção Duplicar quando um novo projeto possuir características semelhantes a outro existente.

⚠️ Depois de duplicar, revise os dados específicos do novo cliente e da nova instalação.

💡 Boas práticas

Antes de enviar uma homologação, confira:

  • ☑️ Cliente correto
  • ☑️ Responsável Técnico correto
  • ☑️ Módulo correto
  • ☑️ Inversor correto
  • ☑️ Quantidades corretas
  • ☑️ Strings e MPPTs
  • ☑️ Dados elétricos
  • ☑️ Distribuidora
  • ☑️ Tensão e tipo de ligação
  • ☑️ Documentação

⚠️ Responsabilidade técnica

O HomologaSolar RT é uma ferramenta de apoio à gestão, conferência e organização de projetos fotovoltaicos.

As análises automáticas dependem dos dados fornecidos pelo usuário e das regras implementadas no sistema.

A conferência final dos dados, o dimensionamento e a responsabilidade técnica permanecem com o Responsável Técnico.

🆘 Encontrou um problema?

  1. Confira os dados digitados.
  2. Confira a ficha técnica do equipamento.
  3. Leia a mensagem apresentada pelo sistema.
  4. Revise o dimensionamento.
  5. Faça uma nova análise.
